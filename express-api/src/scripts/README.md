# 数据库表结构更新脚本

## 背景

在项目开发过程中，数据库表结构可能会随着需求变化而更新。当向已存在的表添加新字段时，需要执行 `ALTER TABLE` 操作来更新表结构。

## 问题

当前项目中，`search_goods_items` 表已经存在，但缺少一些必要的字段（如 `shopId`），导致更新商品详情功能无法正常工作。

## 解决方案

我们添加了表结构自动检查和更新功能，并提供了一个独立的脚本来执行这一操作。

## 使用方法

### 方法一：运行更新脚本（推荐）

```bash
# 在 express-api 目录下执行
npx ts-node src/scripts/update-schema.ts
```

这将检查所有表的结构，并自动添加缺失的字段。

### 方法二：重启应用

我们已经在数据库初始化函数中添加了表结构检查逻辑，所以重启应用也会自动更新表结构：

```bash
# 在 express-api 目录下执行
npm start
```

## 技术说明

- 使用 SQLite 的 `PRAGMA table_info` 命令获取表的当前结构
- 比较当前结构与定义的结构，找出缺失的字段
- 使用 `ALTER TABLE ADD COLUMN` 语句添加缺失的字段

## 注意事项

- 此脚本只能添加新字段，不能修改或删除现有字段
- 如果需要修改字段类型或删除字段，请考虑使用数据迁移方案
